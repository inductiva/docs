## About SWMM
[SWMM](https://www.epa.gov/water-research/storm-water-management-model-swmm) (Storm Water Management Model), developed by the U.S. EPA, is a widely used tool for simulating stormwater runoff, combined and sanitary sewer systems, and other drainage networks. It can perform both single-event and long-term simulations of hydrology, hydraulics, and water quality, including rainfall, runoff, infiltration, and pollutant transport.

## Supported Versions
Inductiva stays up to date with the latest versions of SWMM. Below is a list of the supported versions, along with their respective release dates:

- **5.2.4** (Aug., 2023)

To use a specific SWMM version, simply specify it when initializing the simulator:

```python
swmm = inductiva.simulators.SWMM(\
    version="5.2.4")
```

If you need to use a version not listed here, please feel free to [Contact Us](mailto:support@inductiva.ai).
We’ll be happy to accommodate your request!

## Container Images
Each version of SWMM in the Inductiva API has its own publicly available container image, 
so you can also use it to run simulations. These images are hosted in our Docker Hub repository, 
[Kutu](https://hub.docker.com/r/inductiva/kutu/tags?name=swmm), and you can find the 
Dockerfile details for each version [here](https://github.com/inductiva/kutu/tree/main/simulators/swmm).
