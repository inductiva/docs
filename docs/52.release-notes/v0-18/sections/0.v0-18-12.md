---

## 🛠 SWMM Binary Update

Inductiva is committed to ensuring the best possible experience for users, even when issues originate in the simulator itself. After investigating reports of SWMM tasks being incorrectly marked as “Success” even when simulations failed, we determined that the root cause was **within the SWMM binary itself**. The `runswmm` executable always returned an exit code of 0, even when errors occurred during simulation.

To fix this, we applied a **patch directly to the SWMM source code**, so the binary now correctly returns **non-zero exit codes** when errors happen. This ensures that task status accurately reflects simulation success or failure.
